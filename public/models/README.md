# body.glb 규약

이 폴더에 `body.glb` 를 놓으면 자동으로 마네킹을 대체한다.
파일이 없으면 `src/scene/body/fallbackBody.js` 의 프리미티브 마네킹으로 폴백한다.

## 메시 이름 → 부위 키

접두사 매칭이라 Blender 가 붙이는 접미사(`.001`, `_rib_03` 등)는 그대로 둬도 된다.

| 메시 이름           | 부위 키   | 보고서 항목      |
| ------------------- | --------- | ---------------- |
| `SKIN_TORSO`        | `skin`    | 외표 검사        |
| `SKIN_LIMBS`        | `limbs`   | 사지 검사        |
| `VESSEL` 또는 `HEART` | `vessel`  | ① 순환계         |
| `BONE`              | `bone`    | ② 뼈와 근육      |
| `NERVE`             | `nerve`   | ③ 신경           |
| `WOUND`(선택)       | `wound`   | 흉부 관통상      |

순환계를 심장 하나로 모델링하는 경우가 많아 `HEART` 도 같은 부위로 받는다.

- `VESSEL` / `BONE` / `NERVE` 는 개복 전까지 숨겨진다.
- 계통끼리 영역이 겹쳐도 된다. 전신 골격처럼 큰 부위가 그 안의 심장·신경을 감싸는 경우,
  클릭은 **바운딩박스가 더 작은(= 더 구체적인) 계통**이 가져간다.
- `WOUND` 메시가 없으면 좌흉부(`parts.js` 의 `WOUND_ANCHOR` — 가로는 몸통 박스 비율,
  높이는 신장 대비 비율)에 표식 구체를 자동 생성한다. 앞뒤 위치는 비율로 찍지 않고
  **표피에 광선을 쏘아 표면에 붙인다** — 비율로 찍으면 몸 안에 묻혀 보이지 않는다.
- 이름이 하나도 맞지 않으면 경고를 남기고 폴백 마네킹을 쓴다.

## 자세와 크기

- **직립** 자세로 저장한다(Y=위, +Z=앞). 눕히는 변환은 코드가 한다.
- 크기는 신경 쓰지 않아도 된다. 로드 시 신장 1.74m 로 자동 스케일하고,
  발끝을 바닥에, 좌우·앞뒤 중심을 원점에 맞춘다.
- 카메라 프리셋(시선 중심·거리)은 각 부위의 바운딩박스에서 자동 계산된다.
  보는 각도만 `src/scene/body/parts.js` 의 `VIEW_ANGLES` 에서 조정한다.

## 흔한 문제 — 미러링한 반쪽이 사라진다

몸의 한쪽 절반만 보이고 반대쪽은 회색 그림자만 남는다면, 미러링한 반쪽의
**노멀/면 방향이 뒤집힌 것**이다. 앞면만 그리면 그 반쪽이 통째로 컬링돼 사라지고
그림자만 남는다.

이 프로젝트는 몸을 양면(`DoubleSide`)으로 그려서 그대로도 보이게 해 두었지만,
근본 수정은 Blender 에서 하는 편이 낫다(음영과 성능 모두 나아진다).

1. 오브젝트 선택 → `Object > Apply > Scale` (음수 스케일로 미러링했다면 필수)
2. Edit Mode → `A` 로 전체 선택 → `Shift+N` (Recalculate Normals Outside)
3. 다시 익스포트

## DRACO

DRACO 압축 glb 도 그대로 읽는다. 디코더는 `npm install` 시
`scripts/copy-draco.mjs` 가 `public/draco/` 로 복사한다.
비압축 glb 만 쓸 거라면 이 폴더는 없어도 된다.
